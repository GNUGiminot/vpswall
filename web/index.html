Подключите SSH-туннель и получите токен в терминале сервера.

sudo --preserve-env=SSH_CONNECTION vpswall web token

Токен хранится только в текущей вкладке. Новый токен заменяет предыдущий.

Переход на новый порт

Дополнительный SSH listener с текущими настройками авторизации

Старый порт не закрывается автоматически. Для подтверждения перехода понадобится новое SSH-подключение к новому порту. Таймер отката — 120 секунд.
ssh -N -L 127.0.0.1:8090:127.0.0.1:8090 -p 22 user@server

Команда туннеля запускается на вашем компьютере. Адрес браузера: http://127.0.0.1:8090
